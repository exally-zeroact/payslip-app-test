## なぜ中身を消したか

2026-08-04、**司さんがここを「テスト用」だと思って開いてしまいました**。
中身は 2026-08-02 で止まっていて、その後の直し（iPhoneでExcelが開けない件・最低賃金の発効日など）が
1つも入っていません。**古い方で見ると「直っていない」ように見えます。**

「古い」と書くだけでは足りないので、**中身を消して、開いたら新しい場所へ飛ぶ1枚だけ**にしました。
（消した中身は git の履歴に残っています。コードの正は exally-staging です）

## 残してある物と、その理由

- `index.html` / `404.html` … 案内＋自動転送。**うしろ（`?t=...` や `#...`）を落としません**（Web明細のリンクが死ぬため）。
  古い `meisai.html` などの直リンクも、新しい場所の同じファイルへ移します。
- `sw.js` … **キルスイッチ**。昔このURLで登録された Service Worker が端末に住み着いていると、
  push しても古い画面が出続けます。**消すのではなく、自分を登録解除してキャッシュを消す物を残します。**
- `manifest.json` / `img/` … ホーム画面に入れている人が開いた時に、この案内ページが出るように。

新しい変更はここに入れません。**コードは exally-staging（テスト）と exally（本番）が正です。**
